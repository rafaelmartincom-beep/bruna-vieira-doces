# Bruna Vieira Doces Finos

App de precificação e cadastro de receitas da Bruna Vieira Doces Finos.

- Cadastro de ingredientes com preço pago e tamanho da embalagem
- Receitas com modo de preparo, rendimento, durabilidade e dificuldade
- Precificação por custos fixos, embalagem, mão de obra, lucro e taxa de venda
- Lista de compras por quantidade de doces

Hospedagem planejada: Vercel. Dados e login: Supabase.
